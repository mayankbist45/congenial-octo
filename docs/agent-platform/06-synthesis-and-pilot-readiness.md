# Phase 6: Synthesis And Pilot Readiness

## IC Memo

The IC Memo agent may synthesize completed case artifacts only. It must reference those artifacts and cannot introduce unsupported facts as source evidence.

## Operations

Use OpenTelemetry trace IDs to connect API request, Temporal workflow, tools, and persisted run. Record aggregate token/cost usage, timeouts, source coverage, and failures. Redact secrets and raw sensitive content before export.

## Pilot Gate

A PM can start multiple agents, members can inspect/comment, a PM/CIO can finalize a bounded assessment, and an operator can diagnose every failure from a trace ID. Confirm broker, holdings, and order state are unchanged.

## Deferred

Client sharing, custom agents, trade proposals, and autonomous execution.
